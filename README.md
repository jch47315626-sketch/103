# 103동 — 전투 프로토타입 v0.1

기획서 1단계(프로토타입) 중 **카드형 3라운드 복싱 전투**만 떼어 낸 회색 박스입니다.
"패턴을 읽고, 빠르게, 맞지 않고, 끝낸다"가 재미있는지 확인하는 것이 목표입니다.

## 실행

```bash
npm install
npm run dev      # 브라우저에서 플레이
npm test         # 규칙 테스트
npm run sim      # 봇으로 적마다 1000판 돌려 밸런스 표 출력
npm run build    # dist/ 에 배포용 파일 생성
```

## 전투 규칙 요약

- 감염자는 라운드 시작에 행동을 **예고**한다: 🦷물기 / ✋잡기 / ↔밀기 / 😶비틀거림.
- 태리는 라운드마다 스태미나 3 안에서 카드를 **순서대로** 낸다. 카드 7장은 항상 손에 있다.
- 감염자에게 HP는 없고 **자세**만 있다. 잽·바디로 자세를 0으로 만들면 **머리가 열리고**, 어퍼·코크스크류로만 KO를 낸다.
- 위빙으로 물기를 피하면 **카운터**: 다음 공격 데미지 2배, KO 기준 +3.
- KO가 나면 그 라운드 감염자의 행동은 취소된다. 못 내면 라운드 끝에 예고한 행동이 들어온다.
- 소음: 1라운드 무피격 KO = 0, 라운드가 늦어질 때마다 +1, 코크 빗나감 +1, 밀기 +2, 물림 +1, 못 끝내면 +3.
- 물리면 즉시 게임 오버가 아니라 **감염 타이머**가 시작된다.

| 적 | 특징 |
| --- | --- |
| 일반 감염자 | 자세 3 |
| 기어 오는 감염자 | 자세 2, 낮음: 바디 반감, 코크스크류 빗나감, 어퍼 강화 |
| 감염된 호룡 (보스) | 자세 6, 5라운드, 외눈: 위빙으로 물기를 피하면 다음 라운드 비틀거림. KO 후 텐 카운트 |

## 구조

```
src/rules/   전투 규칙 (화면과 분리된 순수 TypeScript, 시드 고정 난수)
src/sim/     밸런스 봇
src/ui/      회색 박스 화면 (DOM). 복도 맵 단계에서 Phaser를 붙인다.
```

## 배포

`main`에 푸시하면 GitHub Actions가 테스트 → 빌드 → GitHub Pages 배포를 한다.
처음 한 번은 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 바꿔야 한다.
