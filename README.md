# 103동 — 체험판 v0.2 「15층의 첫 밤」

프롤로그(1501호 원펀치) → 15층 복도 밤 탐사 → 복싱 전투 → 새벽 6시 신호까지 한 판이 이어지는 플레이어블 슬라이스입니다.

- **복도**: ← → 로 걷고(시간 안 듦), 문 앞에서 쪽지 넣기(소음 0)·문 열기(소음 1)·기다리기. 행동마다 30분, 0시~6시.
- **소음**: 3부터 가까운 계단실 감염자가 깨어 한 칸씩 다가오고, 6이면 전부 깨고, 9면 '무리'로 밤이 끝난다.
- **문**: 빈집(물자), 생존자, 숨은 주민, 감염자, 피 묻은 집이 시드마다 섞인다. 채아의 공책처럼 빨강 ○ 사람 / 파랑 △ 소리만 / X 피로 표시.
- **신뢰**: 쪽지 2장이면 새벽 신호에 대답한다. 대답한 집 = 선거 날 숨은 표.
- **전투**: 1인칭 시점 — 감염자가 정면에서 다가오고 화면 아래에 태리의 주먹이 보인다. 아래 규칙. 그림은 도형으로 그린 임시 캐릭터, 효과음은 Web Audio 합성음 — 웹툰 그림·녹음으로 바꿀 자리다.

`lab.html`은 전투 수치를 조정하고 봇으로 밸런스를 돌려 보는 실험실이다.

## 실행

```bash
npm install
npm run dev      # 브라우저에서 플레이
npm test         # 규칙 테스트
npm run sim      # 봇으로 적마다 1000판 돌려 밸런스 표 출력
npm run build    # dist/ 에 배포용 파일 생성
```

## 전투 규칙 요약

- 감염자는 라운드 시작에 행동을 **예고**한다: 🦷물기 / ✋잡기 / ↔밀기 / 😶비틀거림.
- 태리는 라운드마다 스태미나 3 안에서 카드를 **순서대로** 낸다. 카드 7장은 항상 손에 있다.
- 감염자에게 HP는 없고 **자세**만 있다. 잽·바디로 자세를 0으로 만들면 **머리가 열리고**, 어퍼·코크스크류로만 KO를 낸다.
- 위빙으로 물기를 피하면 **카운터**: 다음 공격 데미지 2배, KO 기준 +3.
- 코크스크류는 자세 2 이하면 **확정 KO**지만 **느리다**: 피하지 못한 예고 공격(물기·밀기)을 먼저 맞는다. 비틀거림·잡기 예고 때가 기회.
- KO가 나면 그 라운드 감염자의 행동은 취소된다. 못 내면 라운드 끝에 예고한 행동이 들어온다.
- 소음: 1라운드 무피격 KO = 0, 라운드가 늦어질 때마다 +1, 코크 빗나감 +1, 밀기 +2, 물림 +1, 못 끝내면 +3.
- 물리면 즉시 게임 오버가 아니라 **감염 타이머**가 시작된다.

| 적 | 특징 |
| --- | --- |
| 일반 감염자 | 자세 3 |
| 기어 오는 감염자 | 자세 2, 낮음: 바디 반감, 코크스크류 빗나감, 어퍼 강화 |
| 감염된 호룡 (보스) | 자세 6, 5라운드, 외눈: 위빙으로 물기를 피하면 다음 라운드 비틀거림. KO 후 텐 카운트 |

## 구조

```
src/rules/   전투·밤 탐사 규칙 (화면과 분리된 순수 TypeScript, 시드 고정 난수)
src/sim/     밸런스 봇
src/game/    Phaser 3 게임 화면 (타이틀·프롤로그·복도·전투·새벽)
src/ui/      전투 수치 실험실 (lab.html)
```

## 배포

`main`에 푸시하면 GitHub Actions가 테스트 → 빌드 → GitHub Pages 배포를 한다.
처음 한 번은 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 바꿔야 한다.
