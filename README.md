# 103동 — 체험판 v0.2 「15층의 첫 밤」

프롤로그(1501호 원펀치) → 15층 복도 밤 탐사 → 복싱 전투 → 새벽 6시 신호까지 한 판이 이어지는 플레이어블 슬라이스입니다.

- **복도**: ← → 로 걷고(시간 안 듦), 문 앞에서 쪽지 넣기(소음 0)·문 열기(소음 1)·기다리기. 행동마다 30분, 0시~6시.
- **소음**: 3부터 가까운 계단실 감염자가 깨어 한 칸씩 다가오고, 6이면 전부 깨고, 9면 '무리'로 밤이 끝난다.
- **문**: 빈집(물자), 생존자, 숨은 주민, 감염자, 피 묻은 집이 시드마다 섞인다. 채아의 공책처럼 빨강 ○ 사람 / 파랑 △ 소리만 / X 피로 표시.
- **신뢰**: 쪽지 2장이면 새벽 신호에 대답한다. 대답한 집 = 선거 날 숨은 표.
- **전투**: 실시간 1인칭 — 감염자가 정면에서 다가오고 화면 아래에 태리의 주먹이 보인다. 아래 규칙. 그림은 도형으로 그린 임시 캐릭터, 효과음은 Web Audio 합성음 — 웹툰 그림·녹음으로 바꿀 자리다.

## 전투: 실시간 1인칭 복싱

```
Q 왼 훅     W 잽        E 오른 훅      ← 머리 (머리가 있는 열을 쳐야 맞는다)
A 왼 바디   S 명치      D 오른 바디    ← 몸통 (자세를 깎는다)
Z 왼 어퍼   X 턱 어퍼   C 오른 어퍼    ← 어퍼 (느리고 세다, 공격 준비 중이면 끊는다)
   왼쪽        정면        오른쪽

피하기: ← 왼쪽 / ↓·Space 숙이기 / → 오른쪽
```

- 감염자는 머리·목만 유효하다. **머리 체력**이 0이 되면 KO.
- 머리는 좌우로 흔들린다. 화면 아래 열 표시에서 주황색이 지금 머리가 있는 열이다.
- **몸통**으로 자세를 0으로 만들면 비틀거린다: 머리가 가운데에 멈추고 피해 2배. 자세는 시간이 지나면 회복된다.
- 감염자의 **예비 동작**을 보고 맞는 방향으로 피하면 **빈틈**(피해 2배)이 열린다. 너무 일찍 피하면 맞는다.
  - 왼쪽 할퀴기 → `→`/`↓` · 오른쪽 할퀴기 → `←`/`↓` · 물기 → `←`/`→` · 잡기 → `↓`
- 잡히면 피할 수 없다. 곧 무는데, 머리 열의 **어퍼**로 끊어야 한다.
- 스태미나: 머리 1, 몸통 1.5, 어퍼 2, 피하기 1. 초당 1.8 회복.
- **소음**: 6초마다 +1. 할퀴기에 맞으면 +2, 물리면 +1(감염 타이머), 어퍼 헛스윙 +1. 시간 안에 못 끝내면 +3.
  6초 안에 맞지 않고 끝내면 소음 0 — "빠르게, 맞지 않고, 끝낸다."

| 적 | 특징 |
| --- | --- |
| 일반 감염자 | 머리 8, 자세 4, 18초 |
| 기어 오는 감염자 | 머리 6, 바닥 높이라 머리가 A S D 행에 있다. Q W E는 머리 위로 빗나간다 |
| 감염된 호룡 (보스) | 머리 18, 자세 5, 더 빠르다. 외눈 — `←`로 피하면 사각으로 들어가 빈틈이 길다 |
