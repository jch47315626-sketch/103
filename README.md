# 103동 — 체험판 v0.7 「제1화~제5화」

소설 《103동》 1부의 첫 다섯 화를 장면 그대로 따라가는 이야기 중심 체험판이다.
원작 문장으로 장면이 진행되고, 결정적인 순간은 플레이어가 직접 한다 — 결과는 원작대로다.

**태리의 왼쪽 눈은 보이지 않는다.** 싸울 때 화면 왼쪽은 어둡고, 왼쪽 칸(Q A Z)과 왼쪽에서 오는 공격은
한 박 먼저 **왼쪽 귀**로만 들린다. 세훈이 함께 있을 때는 “왼쪽!” 하고 불러 준다.

처음 화면의 **연습 전투**는 원작 밖의 자유 전투(일반·기어 오는 감염자·호룡)다.

## 싸움: 리듬 복싱 (1인칭, 태리의 눈)

심장 박동 드럼에 맞춰 노트가 온다. 감염자 위에 겹친 **3×3 칸**에 테두리가 줄어들어 칸에 딱 닿는 박자에 그 칸의 키를 누른다.

```
Q W E   머리 (빨강)  — 피해 1
A S D   몸통 (파랑)  — 자세를 깎는다. 자세 0 = 4박 동안 피해 2배
Z X C   어퍼 (주황)  — 피해 2
← ↓(Space) →  피하기 (빨간 원) — 감염자 공격
```

- 판정: PERFECT ±60ms / GOOD ±120ms / 그 밖은 MISS. 아무 노트도 없는 칸을 누르면 콤보가 끊긴다.
- 감염자 공격은 예비 동작과 함께 오는 **피하기 노트**: 왼쪽 할퀴기 `→`/`↓`, 오른쪽 할퀴기 `←`/`↓`, 물기 `←`/`→`, 잡기 `↓`.
  놓치면 맞는다 — 물리면 감염 타이머, 할퀴기는 철문에 부딪혀 소음 +2.
- 피하기 바로 다음 박의 **금색 어퍼 = 카운터**(피해 2배). 잡혔다면 그 어퍼가 **탈출** — 놓치면 물린다.
- **소음**: MISS 3번마다 +1, 맞으면 추가, 노래가 끝날 때까지 못 쓰러뜨리면 +3.
  박자를 놓치지 않고 맞지 않으면 소음 0.
- 원작 장면의 싸움은 소설의 동작 순서 그대로 짠 차트다. 하나라도 놓치면 그 순간으로 다시.
  클린치는 키를 누른 채 버티는 노트, 도윤에게 뻗은 스트레이트는 저절로 멈추는 노트다.

| 적 | 템포 | 특징 |
| --- | --- | --- |
| 연습: 일반 감염자 | ♩=100, 12마디 | 머리 26 |
| 기어 오는 감염자 | ♩=108, 10마디 | 머리가 몸통 높이라 머리 노트가 A S D 줄에 온다. 잡기가 많다 |
| 감염된 호룡 (보스) | ♩=116, 16마디 | 머리 50, 8분음표 연타. 외눈 — `←`로 피하면 사각, 카운터 3배 |

차트는 시드로 만들어져 같은 시드면 같은 곡이 나온다. 완벽하게 치면 곡의 약 ⅔ 지점에서 KO,
70%만 맞히면 일반 감염자에게 약 20%, 호룡에게 약 40% 확률로 노래가 먼저 끝난다.

## 구조

```
src/story/script.ts     제1화~제4화 대본 (원작 문장, 장면 순서)

src/game/               Phaser 3 화면 (타이틀·싸움)
```
